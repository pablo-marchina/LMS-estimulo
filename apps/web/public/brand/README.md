# Estímulo web brand assets

Canonical web assets selected from the owner-provided `elemets-estimulo.zip` package.

| Repository asset | Source inside the package | Web preparation | Use |
|---|---|---|---|
| `estimulo-logo-horizontal-color.svg` | `00. Logos/RGB_sem BR/RGB 2/Colorido/_Principal/EPS/Logo_Estímulo.eps` | Converted from the official vector EPS to SVG without redrawing | Primary navigation and authentication logo |
| `estimulo-symbol-color.svg` | `00. Logos/RGB_sem BR/RGB 2/Colorido/_Simbolo/EPS/Logo_Símbolo.eps` | Converted from the official vector EPS to SVG without redrawing | Favicon and large cropped complementary element |
| `estimulo-dots-cyan.svg` | `Elementos/Imagem2.png` | Lightweight SVG transcription preserving the supplied grid, spacing and official cyan | Decorative dot grid |
| `estimulo-chevrons-magenta.svg` | `Elementos/Imagem1.png` | Lightweight SVG transcription preserving the supplied direction, rhythm and official magenta | Decorative directional motif |

The logo and symbol paths come from the supplied official EPS vectors. CSS controls only clear space, scale, positioning, cropping, opacity and responsive presentation; it does not recolor, distort or reconstruct the marks.

CMYK variants, AI/EPS source files, presentation templates and font binaries are intentionally not shipped in the web bundle. Poppins remains the canonical interface typeface and is loaded as a web font.
