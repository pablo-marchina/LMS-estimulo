# Frente 2 — Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the one-line redirect at `/` with a real public marketing landing page: hero + single CTA, institutional stats, an "descubra seu arquétipo" teaser, and a footer — using only existing design-system components and brand tokens.

**Architecture:** A single new Server Component (`apps/web/app/page.tsx`, replacing its current redirect-only content) with no client-side state, no auth check, no data fetching — fully static public content, statically generated by Next.js. Reuses `EstimuloBrand` and `ButtonLink` from the existing design system; no new components, no new dependencies.

**Tech Stack:** Next.js 16 Server Component, Tailwind v4 (existing `@theme` tokens in `apps/web/app/globals.css`), Node's built-in test runner for a static content-assertion test (this repo's established pattern for presentational pages, e.g. `scripts/application/validate-foundation.test.mjs`).

## Global Constraints

- Exactly **one** call-to-action verb across the whole page: "Entrar" (top nav, hero, footer all link to `/entrar`) — no second competing CTA (e.g. no separate "Cadastrar"), per the approved design's "quem nunca acessou não deveria ter que decidir entrar vs cadastrar" principle.
- Institutional numbers must be ones independently confirmed against `ref/estimulo-ref/estimulo-ref/Estímulo-Institucional.md` during planning, not invented: **R$ 420 milhões+ desembolsados em crédito**, **200 mil+ pessoas impactadas**, **NPS médio de 88**, and a **case de sucesso com a Universidade Harvard** (Blended Finance). Other numbers in that source document are ambiguous due to OCR/scrape column-scrambling and must NOT be used.
- The 4 archetypes' name/icon/description are fixed product truth from `ref/estimulo-ref/estimulo-ref/arquetipos_estimulo.md`: 🔨 Fazedor(a) ("Sabe fazer. Está aprendendo a gerir."), 💪 Batalhador(a) ("Tem garra. Precisa transformar garra em estrutura."), 🧱 Construtor(a) ("Tem base. Falta direção."), 🧭 Navegador(a) ("Sabe onde está. Sabe para onde vai."). Use these names/descriptions verbatim.
- Público-alvo leigo em tecnologia: no jargon, no unexplained abbreviations, short sentences.
- No placeholders — every step below is complete, runnable code.
- Reuse existing components (`EstimuloBrand`, `ButtonLink`) and existing Tailwind tokens/utility classes (`display-font`, `animate-in`, `brand-dots-bg`, `rounded-card`, `shadow-card`) — do not invent new design tokens or new shared components for this single page.
- Public-facing copy is Portuguese (pt-BR).
