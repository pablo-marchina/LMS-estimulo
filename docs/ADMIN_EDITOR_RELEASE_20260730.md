# Correções dos editores administrativos — 30/07/2026

Esta entrega consolida o comportamento operacional esperado das áreas administrativas:

- **Interface:** navegação entre páginas sem depender de sessão de participante e edição liberada conforme a permissão efetiva do CMS.
- **Jornadas:** programa opcional, ciclo simples entre rascunho e publicação, exclusão segura, dimensões recomendadas para capas e visualização do conteúdo das aulas.
- **Diagnósticos:** perfis e dimensões configuráveis, um único formulário ativo e migração obrigatória dos arquétipos anteriores ao publicar.

A transição de diagnóstico remapeia atribuições de usuários e restrições de jornadas de forma transacional, preservando resultados e sessões históricas.
